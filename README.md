# 🌌 Sci-Fi Binary Tree Visualizer (科幻风二叉树可视化)

> “代码是逻辑的诗篇，而可视化赋予了它生命。”

这是一个基于 Web 的二叉搜索树（BST）可视化引擎，采用极简的 **HTML/CSS/JS** 单文件实现。

本项目是本人在学习数据结构期间，为了彻底搞懂二叉树遍历逻辑，**心血来潮与 AI 结对编程**（Pair Programming）完成的作品。我们不仅实现了核心算法，还给它穿上了一层“赛博朋克”的科幻外衣。

## ✨ 功能亮点 (Features)

### 1. 核心算法可视化
支持二叉搜索树（BST）的所有标准操作，并配有丝滑的动画演示：
- **动态插入**：自动计算节点位置，智能布局。
- **可视化查找**：高亮显示查找路径，模拟算法寻址过程。
- **全套遍历演示**：
  - 前序遍历 (Pre-order)
  - 中序遍历 (In-order)
  - 后序遍历 (Post-order)
  - 层序遍历 (Level-order / BFS)

### 2. 级联拖拽交互 (Subtree Dragging)
不仅仅是静态展示！你可以随意拖动节点：
- **物理手感**：节点支持任意拖拽，位置实时更新。
- **级联移动**：拖动父节点时，**整棵子树**会像刚体一样跟随移动，保持相对结构不散架。
- **动态连线**：基于 SVG 贝塞尔曲线的连接线，随节点移动实时重绘。

### 3. 沉浸式 UI 设计
- **Sci-Fi Matrix 主题**：深空蓝背景 + 动态六边形网格 + 霓虹发光节点。
- **响应式布局**：左上角极简控制台，操作直观。

## 🛠️ 技术栈 (Tech Stack)

- **HTML5 / CSS3**: Flexbox 布局，CSS 变量管理配色，backdrop-filter 磨砂玻璃效果。
- **JavaScript (ES6+)**: 原生实现，无任何第三方库依赖（No jQuery, No React/Vue）。
- **SVG**: 用于绘制高性能的动态贝塞尔曲线连接。

## 🚀 如何运行 (How to Run)

本项目为**单文件**应用，极其轻量：
1. 下载/克隆本项目。
2. 直接用浏览器打开 `binarytree.html` 即可体验。
3. （可选）部署到 GitHub Pages 可分享给朋友。
